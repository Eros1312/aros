# Cambios

## 0.1.0 — 2026-10-21

Primera distribución pública de Aros, extraída de una aplicación personal previa.

- Nueva identidad Aros y espacio de configuración independiente.
- Demo local con datos sintéticos y sin credenciales de proveedor.
- Configuración explícita de modelos y conectores; servicios externos opcionales.
- API, biblioteca, tareas, proyectos, calendario y motor de trabajos persistentes.
- Espacios generales de Aprendizaje, Eventos y Recursos con ejemplos sintéticos.
- Capturas de la interfaz de escritorio y móvil en el README.
- Regresiones de permisos, revisión de propuestas, fuentes y conversaciones.
- Fixtures PDF generados desde código y exclusión de datos operativos privados.
- Documentación de instalación, contribución, seguridad y límites de validación.
- Cliente SwiftUI experimental, sin distribución binaria para iOS.
